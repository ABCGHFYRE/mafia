# Mafia

A one-phone Mafia party game for 4–20 players. Deal secret roles by passing the phone around, play the night with or without a human narrator (there's a voice narrator built in), and vote out the killers.

Play it: https://abcghfyre.github.io/mafia/

Add it to your Home Screen from the in-app guide to get the full-screen app with the hat icon. Works offline once loaded.
